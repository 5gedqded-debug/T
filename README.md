# Widget

Лёгкое Android-приложение: плавающая иконка батареи поверх всех окон.

- Иконка батареи с заливкой и процентом внутри.
- Справа молния: ⚡ если идёт зарядка, перечёркнутая молния, если зарядки нет.
- Виджет можно перетаскивать пальцем.
- Автозапуск после перезагрузки телефона.

## Сборка
1. Откройте папку в Android Studio (Gradle sync).
2. Build → Build APK(s), установите на телефон.
3. При первом запуске выдайте разрешение «Поверх других приложений».

Требуется Android 8.0+ (minSdk 26).

## Остановить
Смахните уведомление «Widget работает» нельзя (это foreground-сервис), остановить можно через
Настройки → Приложения → Widget → Остановить.
